# MediaLab Documents (JavaFX)

Υλοποίηση τελικής εργασίας για μάθημα Τεχνολογίας Πολυμέσων:
σύστημα διαχείρισης εγγράφων με ρόλους χρηστών, versioning, παρακολουθήσεις και αποθήκευση κατάστασης σε JSON.

## Βασικά χαρακτηριστικά

- **Ρόλοι χρηστών**: `SIMPLE_USER`, `AUTHOR`, `ADMIN`
- **Προεπιλεγμένος διαχειριστής**:
  - username: `medialab`
  - password: `medialab_2025`
- **Διαχείριση εγγράφων**:
  - δημιουργία εγγράφου (v1)
  - τροποποίηση εγγράφου με αυτόματο versioning (v2, v3, ...)
  - διαγραφή εγγράφου και καθαρισμός watch lists
- **Προβολή εκδόσεων**:
  - απλός χρήστης: μόνο τελευταία έκδοση
  - συγγραφέας/διαχειριστής: τελευταία + έως 2 προηγούμενες
- **Αναζήτηση εγγράφων** με φίλτρα κατηγορίας, τίτλου και συγγραφέα
- **Παρακολουθήσεις εγγράφων** με ειδοποίηση για νέες εκδόσεις στο login
- **Διαχείριση κατηγοριών** (admin): προσθήκη, μετονομασία, διαγραφή
- **Διαχείριση χρηστών** (admin): προσθήκη / διαγραφή
- **JSON persistence** στον φάκελο `medialab/state.json`
  - φόρτωση στην εκκίνηση
  - in-memory λειτουργία κατά την εκτέλεση
  - αποθήκευση πριν το κλείσιμο

## Δομή έργου

- `model/`: οντότητες (`User`, `Document`, `DocumentVersion`, `Category`, `Role`, `AppState`)
- `service/`: επιχειρησιακή λογική σε `DocumentManagementService`
- `persistence/`: αποθήκευση/ανάκτηση JSON με `JsonStorage`
- `ui/`: JavaFX GUI (`MediaLabApp`)

## Build & Run

```bash
mvn test
mvn javafx:run
```

## Javadoc απαίτηση

Η κλάση `DocumentManagementService` περιλαμβάνει javadoc για κάθε public μέθοδο.

## Παραδοχές

- Για απλότητα, η τροποποίηση/διαγραφή εγγράφου από AUTHOR επιτρέπεται μόνο στον δημιουργό του εγγράφου.
- Κατά την προσθήκη χρήστη από GUI ανατίθεται αυτόματα μία κατηγορία (η πρώτη διαθέσιμη) ώστε να τηρείται η απαίτηση πρόσβασης σε τουλάχιστον μία κατηγορία.
- Όταν διαγράφεται κατηγορία, διαγράφονται και τα έγγραφα της κατηγορίας και καθαρίζονται οι παρακολουθήσεις.
